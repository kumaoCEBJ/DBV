## 右クリックの特殊操作
* フィルター : 指定した要素を除外対象にする(種族/装備)
* スキル選択 : 指定したカテゴリを入力欄にコピー
* シミュ : 選択したスキルをOr対象⇔選択したスキルを除外対象

## ユニットの倍率計算に使用するスキル
* ｢多段攻撃/全力攻撃/心核穿ち/巨人狩り/無効喰い/乾坤一擲/疾風迅雷/確率追撃/集約攻撃/範囲攻撃/加速進化/連携攻撃/致命必殺/カブト割/次元斬撃｣

## ゲーム内の説明と一致しなかったもの
* コカトリス : ｢全力攻撃｣→｢全力攻撃 999｣
* ｢〇〇赦免｣ : 昼夜不一致の防御半減は無効だがマイナスの地形効果は有効
* ｢英雄覇気｣ : ｢師団指揮｣+｢師団支配｣→｢師団活性｣+｢師団指揮｣+｢師団支配｣
* ｢罠の領域｣ : ｢地形無効｣/｢決戦領域｣で無効

## シミュの例外
* 撃破金運とグルメ魂のみ重複指定可能
  * 重複指定と除外指定が重なった場合は例外的に除外を無効

## 操作
1. 左クリック : 決定/表示の切り替え/表示の固定/ドラッグアンドドロップ(以下D&D)
    * 表示の切り替え
      * ユニット詳細のスキル一覧の通常/統合
      * 師団詳細のターゲット一覧のHP値/HP割合
    * 表示の固定(解除は右クリック)
      * ユニット/師団一覧のユニット、称号一覧の称号/メダリオン、装備一覧の装備/カテゴリ
    * D&Dの対象 : ユニット/師団/称号/装備/戦術効果/検索結果/シミュ結果/シミュ設定/シミュ詳細設定/一括処理
      * 師団のD&Dは師団一覧の師団番号が対象
2. 右クリック : 解除/削除/一部特殊操作
    * 師団番号を右クリックで師団解散
    * 特殊操作対象
      * フィルター : 指定した要素を除外対象にする(種族/装備)
      * スキル選択 : 指定したカテゴリを入力欄にコピー
      * シミュ : 選択したスキルをOr対象にする⇔選択したスキルを除外対象にする

## `不具合を認識しているが修正出来ないもの`

    * ドロップ可能かどうかを表示する設定が常に許可状態
      * ドロップ時に判定をしているので解決扱い

    * 対応予定なし

## 一括処理
指定した師団に対して処理します。
  * 師団解散/称号解除/装備解除
  * 検索/解除 : ボタン下の枠線内に要素をD&D
    * 検索 : 重複する要素を検索
    * 解除 : 重複する要素を解除
  * 全検索 : 上限を超えた装備とユニットの検索
  * 出力 : クリップボードに師団の情報をコピー

## ユニット詳細
* ユニットの情報を全て表示します。
* 加護や特攻の文字色は通常/称号/装備で分類しています。
* スキルの統合表示の文字色は攻撃系/防御系/活性系/その他で分類しています。
* ユニットの倍率/減算の表示は特定のスキルのみを使用した簡易的な計算処理です。
  * リーダースキルの反映は師団一覧のユニットのみ
  * 倍率のクリティカルダメージはユニットの速度を除外
  * ユニットの倍率計算に使用するスキル
    * ｢多段攻撃/全力攻撃/心核穿ち/巨人狩り/無効喰い/乾坤一擲/疾風迅雷/確率追撃/集約攻撃/範囲攻撃/加速進化/連携攻撃/致命必殺/カブト割/次元斬撃｣

## 検索
指定した要素を持つものを検索結果に表示します。
  * ユニット名検索 : 一文字でも一致していたら該当
  * スキル検索 : スキルの値の高い順にソート
  * 戦術スキル検索
    * 選択した効果が一つの場合はその効果でソート
    * 二つ選択している場合は検索条件1でソート

## シミュ
指定したスキルとフィルターの設定から候補を作り、総当たりする処理です。
ユニットは｢パッシブ｣/｢リーダー｣/フィルターの｢加護｣/｢特攻｣に該当する場合に候補に追加します。
1. 候補が多いほど処理に時間がかかり、結果が多いほど表示に時間がかかります。
    * 出来るだけ条件を設定して下さい。
      * 具体的にはスキルの下限やフィルターを設定すると効果が大きいです。
    * ｢中止｣ボタンはタイミング次第で中止出来ない場合があります。
    * オプションに追加の設定があります。
2. 左右クリックで各スキルの状態を変更します。
    * 有効:And(左)/Or(右)/除外(右)、無効(左)
      * Andは指定したスキルを全て所持します。｢A and B and C｣
      * Orは指定したスキルの中から一つだけ所持します。｢A or B or C｣
        * ｢A or B and C or D｣のような指定は出来ません。
      * 除外の対象はパッシブスキル/リーダースキルのみです。称号/装備は詳細設定から除外して下さい。
3. 通常シミュと詳細シミュがあります。詳細シミュは通常シミュで作る候補の中から選択して実行します。
    * 加護と特攻をフィルターに指定した場合、その条件を満たすだけで候補に追加します。
    * 称号や装備の簡易的なBAN機能があり、そのシミュでは候補に追加しません。
    * シミュ結果一覧はスキル設定の1～3番目のスキルの値の高い順でソートします。
      * 単純に上から1～3番目の判定です。例えば4番目のスキルのみを有効にしてもソートしません。
      * 倍率のオプションを追加した場合、1.倍率、2.スキル設定の1番目、3.2番目でソートします。
    * ｢撃破金運/グルメ魂｣のみ重複指定が可能です。
      * 重複指定と除外指定が重なった場合は例外的にその除外指定は無効になります。
    * シミュ結果に｢専守防衛｣のようなスキル値のないスキルが重複して表示されることがあります。
      * 例えば｢専守防衛｣と｢何か｣の装備がありその｢何か｣も指定されていた場合が該当します。
        * 組み合わせの一例としてその結果も含める方が柔軟性があると判断し残しています。
          * 今後変更する可能性があります。
    * 詳細設定にユニット/称号/装備をD&Dすると他の要素を無効にしてその要素を有効にします。
    * シミュのフィルター:種族の｢血(血の起源)｣と｢無(無貌の血)｣はパッシブスキルで判定しています。
      * 例えば種族｢何か｣と｢血の起源｣を両立したい場合はスキル設定に｢血の起源｣を指定して下さい。
4. ｢トレハン師団｣は指定した設定でトレハン用の師団を作成します。
    * 総当たりではないので最高値ではない場合があります。
      * 処理にかなりの時間がかかります。下限と装備の設定をして下さい。
    * ｢トレハン｣以外のスキルをリーダースキルに指定することは出来ません。
      * リーダースキルに｢トレハン｣を所持するユニットがいない場合は処理を中止します。
    * 通常シミュでは実行出来ません。
    * アシストスキルは指定出来ません。
    * 糧食を除外しています。｢トレハン｣以外のスキルを設定しても糧食は候補に追加しません。
    * 結果一覧のスキル表記の優先度は｢次元斬撃｣ > ｢遠隔攻撃｣ > ｢専守防衛｣です。

## 称号装備ユニット一覧
* 称号一覧の称号は｢<<｣が接頭、｢>>｣が接尾を表しています。
* 装備一覧の装備の文字色は上限に達すると赤色になります。
* 称号/装備一覧の各詳細を左クリックすると｢検索｣を実行します。
* ユニット一覧の上部は全ユニット一覧、下部は師団一覧です。
* アイコンの枠線の色は通常/リーダー/表示の固定/リーダー+表示の固定で分類しています。

## 師団一覧
* 師団番号｢0｣の師団はコピー用の師団です。
* リーダーやアシストスキルの変更は簡易師団/師団詳細で行います。

## スキル選択
* スキル選択の上部はスキルのカテゴリ、下部はスキルです。
* 称号/装備一覧を表示した状態でカテゴリを右クリックすると入力欄にコピーします。
* シミュを表示した状態でスキルを右クリックすると入力欄から削除します。

## フィルター
* 種族/装備の要素を右クリックするとその要素を除外します。
* メダリオンのNew指定はそのユニットに必要な素材の最終位置にあるものを指定します。
* 特攻｢無｣のフィルターはユニットに対して有効です。

## 師団詳細
師団番号をマウスオーバーすると師団の所持スキルと簡易的なステータス等を表示します。
1. ｢計算｣ : 戦闘開始直後を想定したステータス等とターゲットを表示します。
    * ターゲットは各ユニットのHPと防御のみで計算し、隊列等は考慮していません。
    * アシストスキルで使用する知力は｢計算｣前の簡易値と｢計算｣後の詳細値があります。
    * 計算結果のステータスはゲームとの誤差が発生することがあります。
      * レベルから推測した経験値を使用しているので同じレベルでも一致しないことがあります。
      * 複雑な状況の場合は実装した処理が誤っている可能性があります。
    * ｢計算｣で使用する師団のアシストスキル
      * ｢師団活性/〇〇布陣/師団指揮/〇〇指揮/バリアー/兵士運搬/地形無効/決戦領域/正々堂々｣
2. ｢切替｣ : 師団活性枠/師団指揮枠の想定値と全パターンのターゲットを表示します。
3. ユニットアイコン下の入力欄はHP割合/レベル/武功/弱体値を個別に適用するために使用します。
    * 有効/無効は入力欄横のチェックボックスで切り替えます。無効の場合は右側の全体用の値を使用します。
    * 弱体値はステータス別の指定は出来ません。
    * ｢死の軍勢/軍団活性/軍団指揮/師団活性/師団指揮｣は他の師団の値を入力して下さい。
    * ｢愚者の嘘/結界の歪/師団弱体｣は相手の師団の値を入力して下さい。    
    * 入力された値がそれぞれの上限を超える場合は上限の値に設定するか処理を中止します。
    * 忠誠は報酬計算に使用します。個別の適用は出来ません。
4. ｢計算｣後に縦に並ぶユニットアイコンの中で一番上のアイコンが想定されるターゲットです。
    * アイコン下の数値はターゲットが切り替わるHPです。
5. ボーナスは0～100の値でそのセーブデータで得た経験値から算出します。
    * ボーナスは各スタンスのステータス上昇に追加します。
      * 進撃スタンス : 攻撃に3+ボーナス
      * 防備スタンス : 防御に5+ボーナス
      * 計略スタンス : 速度と知力に4+ボーナス
      * 乱戦スタンス : 全種に1+ボーナス/2
    * ボーナスを推測するのは難しいのでゲーム内で直接確認して下さい。
      * 確認方法は同じ戦闘でスタンスだけ変更してステータスの変動を見ます。進撃→防備が手軽です。
    * ボーナスのざっくり参考値(周回数とそのセーブデータの最高レベル)
      * 周回数0レベル84 : 67
      * 周回数1レベル119 : 76
      * 周回数2レベル150 : 100
6. 所持スキル一覧の｢終の奇跡｣は師団内で一番高い値のみ表示しています。
    * ゲームではスキルを所持しているユニット毎に発動します。
7. 拠点の情報はデウスモードのものです。

## BAN設定
* 指定した設定で表示する要素を更新します。
* 反映には｢更新｣ボタンを押下する必要があります。
* 配置済みの師団一覧にも反映します。
* 武将ユニットの指定条件はユニット詳細の名前の上に表示されています。
* 一部一般ユニットのBAN設定が機能しないことがあります。
  * 原因はニューゲーム時点で雇用済みのユニットの例外処理です。

## オプション
* ｢データを保存して～｣を有効にすると各種データを保存して次回起動時に読み込みます。
* 無効にした場合はデータを削除します。
  * 保存/削除のタイミングはページ更新/終了時です。ブラウザのローカルストレージを使用しています。
  * キャッシュは無条件で保存されます。インストールでアプリ利用出来ますが詳細は把握していません。
* ｢シミュ結果に倍率を反映する｣を有効にするとシミュ結果一覧を倍率→1番目のスキル→2番目の順でソートします。
* ｢キャンセル命令～候補数｣はシミュ結果の候補数が指定した値を超えた場合に処理を中止します。
  * ｢トレハン師団｣の場合は師団数が指定した値/10の値を超えた場合にも処理を中止します。
  * 中止処理ではなく中止命令なのでタイミング次第では中止出来ません。
